## Sobre o projeto

Este é meu portfólio pessoal: uma página responsiva criada para reunir, em um só lugar, quem sou, as tecnologias que estudo, os projetos que desenvolvo e as redes onde compartilho minha evolução.

O visual segue uma direção escura e moderna, com foco em leitura, navegação simples e uma apresentação profissional em computadores, tablets e celulares.

## O que você encontra

- Apresentação pessoal e objetivos profissionais.
- Habilidades em Java, Dart, Flutter, HTML, CSS e JavaScript.
- Projetos públicos selecionados diretamente do meu GitHub.
- Links para GitHub, LinkedIn, YouTube, Twitch e Instagram.
- Navegação adaptada para dispositivos móveis.
- Animações com respeito à preferência de movimento reduzido.
- Estrutura semântica e cuidados de acessibilidade.
- Cartão próprio para compartilhamento em redes sociais.

## Executar localmente

Clone o repositório e abra `home/index.html` no navegador. Se preferir servir a página localmente:

~~~bash
python3 -m http.server 8000
~~~

Depois acesse `http://localhost:8000/home/`.
